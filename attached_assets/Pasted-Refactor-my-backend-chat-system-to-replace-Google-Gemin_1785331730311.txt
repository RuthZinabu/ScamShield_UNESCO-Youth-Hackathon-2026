Refactor my backend chat system to replace **Google Gemini (`@google/genai`)** with **OpenRouter** while keeping the existing API endpoints, database logic, and frontend unchanged.

### Requirements

Do **not** change any routes or endpoint URLs.

Keep these endpoints exactly the same:

* `GET /api/chat/conversations`
* `POST /api/chat/conversations`
* `GET /api/chat/conversations/:id`
* `DELETE /api/chat/conversations/:id`
* `POST /api/chat/conversations/:id/messages`

### Replace Gemini

Remove:

* `@google/genai`
* `GoogleGenAI`
* `getGeminiClient()`
* `generateContentStream()`
* all Gemini-specific request formats (`contents`, `parts`, `systemInstruction`, etc.)

Install and use the official OpenAI SDK:

```ts
import OpenAI from "openai";
```

Configure it to use OpenRouter:

```ts
const client = new OpenAI({
  apiKey: process.env.OPENROUTER_API_KEY,
  baseURL: "https://openrouter.ai/api/v1",
});
```

Use the environment variable:

```
OPENROUTER_API_KEY
```

instead of:

```
GEMINI_API_KEY
```

### Streaming

Continue using Server-Sent Events (SSE).

Keep these headers:

```ts
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive
```

Use OpenRouter streaming via:

```ts
client.chat.completions.create({
    stream: true,
    ...
})
```

Send every streamed token to the frontend exactly like the current implementation.
