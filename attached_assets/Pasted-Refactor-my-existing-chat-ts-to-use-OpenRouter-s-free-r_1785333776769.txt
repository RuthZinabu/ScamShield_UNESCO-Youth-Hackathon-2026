### Streaming

Continue using streaming exactly as before.

The route must still:

1. Save the user message.
2. Load conversation history.
3. Call OpenRouter.
4. Stream tokens to the frontend using SSE.
5. Save the assistant response.
6. Update `conversation.updatedAt`.
7. Send `{ done: true }` when complete.

### Error handling

Wrap the AI request in a `try/catch`.

If OpenRouter returns any error:

* Log the complete error.
* Return a readable SSE error message instead of crashing.
* Always close the stream cleanly.

Example behaviour:

```ts
catch (error: any) {
  console.error("OpenRouter error:", error);

  res.write(
    `data: ${JSON.stringify({
      error: error?.message ?? "Unable to generate an AI response."
    })}\n\n`
  );

  res.write(`data: ${JSON.stringify({ done: true })}\n\n`);
  res.end();
}
```
