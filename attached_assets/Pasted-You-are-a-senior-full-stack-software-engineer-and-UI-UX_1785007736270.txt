You are a senior full-stack software engineer and UI/UX designer.

Build a modern, production-ready web application called "ScamShield AI" (working title).

MISSION

The platform is NOT a scam detector.

Its mission is to improve Media and Information Literacy (MIL) by helping users critically evaluate suspicious digital content before making decisions.

The AI should NEVER make decisions for the user.

Instead, it should:

• Highlight possible warning signs.
• Explain why those warning signs matter.
• Ask reflective questions.
• Encourage verification.
• Teach digital literacy.
• Help users make informed decisions independently.

The application should feel educational, trustworthy, modern, and simple.
